# Pizzería con Delivery — Proyecto Bootcamp bc-expressjs

## Presentación

Este repositorio contiene las entregas semanales del proyecto del bootcamp **bc-expressjs**, dictado por el profesor Erick Granados (SENA).

Cada semana se desarrolla una versión adaptada del proyecto propuesto en el material de clase, aplicada al dominio asignado a este estudiante: **Pizzería con delivery**.

## Dominio asignado

**Pizzería con delivery**

### Entidades principales

- **products** — productos del menú de la pizzería (pizzas, bebidas, adicionales, etc.)
- **orders** — pedidos realizados por los clientes
- **deliveries** — entregas/domicilios asociados a cada pedido
- **customers** — clientes de la pizzería

Todo el código, modelos, datos de ejemplo y nombres de recursos de este repositorio están adaptados a este dominio (no al ejemplo genérico del material de clase).

## Estructura de entregas

Cada semana del bootcamp se entrega en una rama independiente dentro de este mismo repositorio, siguiendo el formato:

```
week-01
week-02
week-03
...
```

El número de semana siempre se escribe con dos dígitos. Este es el único repositorio usado durante todo el trimestre para las entregas de bc-expressjs.

## Proceso de entrega semanal

1. Adaptar el proyecto de esa semana al dominio de Pizzería con delivery (recursos, campos, datos de ejemplo).
2. Subir el código a la rama `week-<NN>` correspondiente en este repositorio.
3. Enviar el correo de entrega a `profeerickgranados@gmail.com` con el siguiente formato:

   ```
   Asunto: bc-expressjs semana <NN> ficha <ficha>
   Cuerpo: https://github.com/<usuario>/<este-repo>
   ```

4. Realizar la entrega antes del plazo: **2 días calendario antes de la próxima clase, hasta las 11:59pm**.

## Feedback

El feedback de cada entrega es compartido directamente por el instructor Erick Granados; no existe un portal de consulta propio.
